# Biblioteca de Aula 6º A

Aplicación web para la gestión de préstamos y aportaciones de libros de la clase de 6º A (curso 2026-2027).

## Características

- Gestión de préstamos actuales de cada alumno
- Registro de libros aportados a la biblioteca
- Catálogo completo de la biblioteca
- Seguimiento de fichas de lectura por trimestres
- Búsqueda de alumnos y libros
- Datos guardados automáticamente en el navegador
- Exportar / importar datos en JSON

## Uso

Abre `index.html` en cualquier navegador moderno.

Los datos iniciales se cargaron desde el Excel de la clase.

## Dominio

Preparado para ser publicado en el dominio de Andel Manager.
